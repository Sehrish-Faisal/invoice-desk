Integration guide

Your company workspace

One company per installation. Connections share this company's workspace; they are not separate company accounts. API access is limited to each connection's imported records.

1. Create a connection

API keys expire after 90 days. Store keys in your server's secret manager, never in browser code.

Save your new secret

Shown once for 60 seconds. Save it securely before leaving this screen.

2. Configure connection

Webhook destination

Approved, returned and exported invoice events contain record IDs only. Your receiving system must verify the signature and fetch approved invoice details using its API key.

Enable only an endpoint authorized to receive your company data. Public HTTPS on port 443 is required; private network destinations and redirects are blocked. Disabling or changing the endpoint cancels pending deliveries. A request already sent cannot be recalled.

3. Map and import CSV

Import suppliers before purchase orders. Preview validates the entire batch without saving. Identical external IDs are safely replayed; changed records are rejected. Existing supplier names or order references cannot be silently linked or overwritten.

Preview the CSV before importing.

UTF-8, comma-separated, up to 100 KB, 500 rows and 100 records per batch. Supported currencies: PKR, USD, EUR and GBP. CSV imports do not update stock or make payments.
